# Computer Architecture – Problem Solving

Python implementations of binary arithmetic and logical shift operations for the **Computer Architecture (25AIM34)** course at New Horizon College of Engineering.

## 📌 Programs

### 1. Signed Binary Arithmetic Using 2's Complement

Performs signed arithmetic using 2's complement representation.

**Operations:**
- `24 + (+17)`
- `(-25) + (-18)`

**Features:**
- Converts signed decimal numbers into 8-bit 2's complement binary.
- Performs arithmetic operations.
- Displays results in binary and decimal formats.
- Checks for 8-bit signed arithmetic overflow.

### 2. Logical Shift Operations

Demonstrates logical shifting of binary numbers.

**Operations:**
- Logical left shift of `1111110110` by 2 positions.
- Logical right shift of `10010100` by 2 positions.

**Features:**
- Displays the original binary number.
- Demonstrates each shift step.
- Displays the final result in 8-bit binary format.

## 🛠️ Technologies Used

- **Language:** Python 3
- **Topics:** Binary arithmetic, 2's complement, logical shifts, and overflow detection.
